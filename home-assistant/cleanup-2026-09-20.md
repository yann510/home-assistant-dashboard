# Home Assistant cleanup — September 20, 2026

Removed unused software after inspecting the live configuration, active
integrations, installed dashboard, database, and container connections.

## Removed

| Component | Evidence / reason |
| --- | --- |
| Log Viewer | Deprecated, detached from its repository, stopped. |
| Terminal & SSH | Duplicate of Advanced SSH; no host SSH port published. |
| NGINX Home Assistant SSL proxy | Stopped and configured for manual startup. |
| Nginx Proxy Manager | In an error state, manual startup; existing proxy configuration preserved in full backup. |
| MariaDB | No application tables and no connected clients other than the audit query. Home Assistant has no recorder DB override or SQL integration and actively uses its SQLite database. |
| Button Card, RGB Light Card, Big Slider Card, Mushroom | No references in the active React dashboard or YAML, no configured additional Lovelace dashboards. Uninstalled through HACS, which also removed their Lovelace resources. |
| cors-anywhere / gifted_faraday | Legacy 2023 container, no mounted data, no active connections, and no references in deployed dashboard assets or YAML. Archived, stopped, verified dashboard, then removed container and image. |

No client detected during the audit does not prove that a legacy external
consumer can never exist. The CORS filesystem and container configuration
were archived to permit recovery if an occasional consumer is later identified.

## Preserved

Only two add-ons remain: **HAKit** and **Advanced SSH & Web Terminal**;
both are running. Active device integrations and HACS are preserved, including
Hilo, LocalTuya, SamsungTV Smart, Lepro, Sonos, SmartThings, Tuya, Spotify,
House Mood and dashboard attention.

Disabled HomeKit and Eight Sleep configuration entries retain their pairing
and account setup. They are not running and deleting them would provide little
benefit. Historical configuration backups and the local TV-card source/resource
are also preserved; these are not running add-ons or proxy services.
